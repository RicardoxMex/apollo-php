## Important Context

- `socket.on('notification', (data) => …)` es la API principal del spec §9/§24.
- `socket.off(event, fn)` quita un listener; sin `fn` quita todos.
- `socket.emit(event, data)` y `socket.send(obj)` para enviar al servidor.
- Reconexión re-suscribe automáticamente los canales que el cliente había suscrito antes de la caída.
