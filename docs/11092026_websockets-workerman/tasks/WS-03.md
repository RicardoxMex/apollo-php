## Goal

Cerrar el bucle app→servidor: el `HttpEventBus` (app-side) publica vía HTTP al endpoint `/internal/push` del servidor. `ConnectionManager` aprende `sendToUser()` y `sweep()`. `RealtimeConfig` y `RealtimeManager` aceptan las nuevas claves y el flag `inProcess` (mode-aware). `RealtimeServiceProvider` se enlaza al modo app. `config/realtime.php` resuelve `WEBSOCKET_*` con fallback `REALTIME_*`.

## Pasos

1. `core/Realtime/Bus/HttpEventBus.php`:
   - Implementa `EventBus`.
   - `__construct(RealtimeConfig $config)` — usa `internalHost`, `internalPort`, `appSecret`.
   - `publish($topic, $payload)`: HTTP POST con `stream_context_create([...http])`, timeout 1s, body `{"channel":$topic,"payload":$payload}`, header `Authorization: Bearer <app_secret>`.
   - `subscribe`/`consume`/`consumePattern`: `throw new \BadMethodCallException()`.
   - Errores (`connection refused`, 5xx, timeout) → `error_log("[HttpEventBus] publish failed: …")` y retorno silencioso.
2. `ConnectionManager`:
   - Añadir `sendToUser($userId, $payload): int` (devuelve nº entregado).
   - Añadir `sweep(int $timeoutSeconds): int` que llama `disconnect` en conexiones con `lastSeen` antiguo.
3. `RealtimeConfig`: accessores `internalHost`, `internalPort`, `enabled`, `publicUrl`, `sslEnabled`, `sslLocalCert`, `sslLocalKey`. Mantener los existentes.
4. `RealtimeManager`:
   - `__construct(array $config, ?callable $redisFactory = null, bool $inProcess = true)`.
   - `bus()`: si `!$inProcess && driver==='local'` → `HttpEventBus`; en caso contrario comportamiento actual.
   - `sendToUser($userId, $event, $data, ?string $channel = null)`: helper que delega a `broadcaster()->emit($event, $data, $channel ?? 'private-user.{id}')`.
5. `RealtimeServiceProvider`:
   - `new RealtimeManager(config('realtime', []), null, false)` (app mode).
   - Registra `NotificationService` como singleton.
6. `config/realtime.php`: añadir claves por defecto, resolver `WEBSOCKET_*` con fallback `REALTIME_*`. Mantener el nombre raíz `realtime` (el provider lee `config('realtime', [])`).
7. `websocket/internal_http_server.php`: entry del HTTP interno. Acepta POST `/push`, GET `/status`, GET `/auth`. Mismo bootstrap de la app. En Windows: lanzado por `realtime:start` con `proc_open`; en Linux: Worker adicional dentro del mismo `server.php`.

## Output Contract

Devolver: archivos, `php -l` verde, evidencia de la firma extendida de `RealtimeManager` (los tests del manager siguen pasando), y un test de humo de `HttpEventBus` apuntando a un endpoint inexistente (no debe lanzar excepción).
