## Goal

Crear la API de alto nivel `NotificationService::sendToUser` que persiste + emite. Actualizar `RealtimeChannel` para emitir el frame del spec §7 (`event=notification`, `data={id,type,title,message,data,created_at}`). Reescribir los comandos CLI para arrancar/detener/reiniciar el servidor Workerman (Windows + Linux). `realtime:test` reporta Workerman.

## Pasos

1. `NotificationService`:
   - `__construct(NotificationManager $manager, ?RealtimeManager $realtime = null)`.
   - `sendToUser($userId, $type, array $payload, array $options = []): array`:
     - Normaliza payload (`title`, `message`, `data`).
     - Persiste vía repo (`$manager` despacha por `database`).
     - Emite vía `RealtimeChannel` (canal `realtime`) si está registrado.
     - Devuelve el registro creado (id, type, title, message, data, created_at).
   - `sendToUsers(array $userIds, ...)` (helper).
2. `RealtimeChannel::send()`:
   - Construye el payload: `id` (del repo), `type`, `title`, `message`, `data`, `created_at`.
   - Llama `$realtime->broadcast("private-user.{$userId}", "notification", $payload)`.
3. CLI:
   - `RealtimeStartCommand`: bootstrap app (puede reusar el `apollo` boot? — sí, requiere autoload+config y luego `require websocket/server.php` con `$argv = [basename, 'start', ...extra]`).
   - `RealtimeStopCommand`: lee pid, mata (taskkill/posix).
   - `RealtimeRestartCommand`: stop + background launch.
   - `RealtimeStatusCommand`: lee pid, ping HTTP `/internal/status` (si está vivo).
   - `RealtimeTestCommand`: chequea PHP, `class_exists(Workerman\Worker)`, Redis, BD, `app_secret`.
4. `php -l` verde en todos los archivos.

## Output Contract

Devolver: archivos, `php -l` verde, `realtime:test` corriendo (sin servidor activo) muestra estado, y un test unit de `NotificationService` (placeholder si no se hace en WS-07, aquí sólo el happy path manual).
