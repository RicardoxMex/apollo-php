## Goal

Extender el cliente JS para que:
1. Envíe el JWT en la URL (`?token=<jwt>` o lo acepte como opción).
2. Exponga una API top-level `on(event, cb)`, `emit(event, data)`, `off(event)`.
3. Maneje frames `{event, data}` y los emita como eventos top-level.
4. Mantenga la API de `channel(name).listen(event, cb)` por BC.
5. Preservar reconexión con backoff y heartbeat ya existentes.

## Pasos

1. Añadir `token` a `DEFAULT_OPTIONS`.
2. `connect()`: si hay `token`, añadirlo a la URL `?token=…` (mantener `key`).
3. `handleMessage`: si el frame tiene `event` y `data` (sin `type`), llamar `this.emit(msg.event, msg.data)`. Mantener el manejo de `{type:'event',channel,event,data}` para BC con canales.
4. Añadir API top-level: `on(event, cb)`, `off(event)`, `emit(event, data)`, `send(obj)`.
5. Preservar reconexión y heartbeat (sin cambios).
