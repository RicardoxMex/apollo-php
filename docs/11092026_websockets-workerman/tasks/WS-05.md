## Goal

Exponer el API REST del módulo realtime. Añadir las rutas de lectura de notificaciones con autorización por dueño. Registrar `Realtime` en `config/apps.php` para que el API quede activa por defecto.

## Pasos

1. `config/apps.php`: añadir `'Realtime'` al array `registered`.
2. `Routes/api.php`: añadir
   - `GET /notifications` (auth)
   - `GET /notifications/{id}` (auth)
   - `POST /notifications/{id}/read` (auth)
   - `POST /notifications/read-all` (auth)
3. `RealtimeApiController`:
   - `notifications(Request)` ya existe; refactor para pasar repo en propiedad (inyección).
   - `notification(Request, $id)`: 404 si no es del user; 200 con el registro.
   - `markAsRead(Request, $id)`: 403 si no es del user; 200 al marcar; 404 si no existe.
   - `markAllAsRead(Request)`: 200 con count.
4. Validación: no exponer el `user_id` recibido del cliente en `/v1/realtime/auth` cuando el cliente está autenticado (tomar del `$request->user()`).

## Output Contract

Devolver: archivos, `php -l` verde, `php apollo route:list` muestra las nuevas rutas, y un test feature mínimo (puede ser manual con curl + JWT de prueba) que valide la autorización.
